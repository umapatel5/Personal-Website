Umao

Umao is an AI technical interview simulator that helps users practice coding interviews in a more realistic environment. It combines a coding workspace, interview-style prompts, voice interaction, webcam analysis, automated test feedback, and AI-generated performance notes.

  • Four-language coding workspace with Monaco Editor
  • Automated testing flow for interview-style coding problems
  • AI feedback to help users understand strengths and improvement areas
  • Voice, webcam, and Tavus-based interview features for a more realistic practice experience

Tech stack: Next.js, React, TypeScript, Python, Monaco Editor, Tavus, and AI APIs.
